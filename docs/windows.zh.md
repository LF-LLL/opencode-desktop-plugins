# Windows 手工指南

[English](windows.md) · [项目首页](../README.zh.md)

只在作者当前 Windows 电脑和当前使用的 OpenCode Desktop 上测试过。这不是 SAP 官方插件。

## 安装

1. 在 GitHub 选择 **Code → Download ZIP**，解压。已经 clone 的用户直接用本地仓库。
2. 打开仓库的 **plugins** 文件夹，里面是三个独立插件文件夹，选需要的即可。
3. 打开文件资源管理器，在地址栏输入 `C:\Users\<your user>\.config\opencode`，把 `<your user>` 换成自己的用户目录名，例如 `C:\Users\alex\.config\opencode`，按 Enter。这是文件夹地址，不是命令；不要直接输入 `~`。
4. 没有 **plugins** 文件夹就把仓库里的 **plugins** 整个复制进去；已有则打开它，只复制需要的插件文件夹。不复制整个仓库，不替换其他插件。
5. 在 **设置 → 扩展 → 插件**确认开关已打开。主题在 **设置 → 外观 → 主题**选择 **Fiori Horizon Light**，使用浅色模式。

不用编译、命令行、安装 Node 或改配置。插件里的 `test.cjs` 可以保留，日常使用不会自动运行。

> 提示：遇到同名文件时点取消，先确认电脑上是否已有旧版。旧版通过显式配置加载的，应更新原位置，不要再安装第二份。

加载失败可点对应的 **Reload**。列表没更新时，先保存工作，再关闭并重新打开桌面窗口。自定义配置目录需要另行确认，不要复制别人的整份配置。

内部名称 **fiori-horizon-light** 和 **desktop-workflow** 是为兼容保留的。

## 使用

- **主题**：Fiori Horizon 同时调整主对话区的颜色和文档浏览区的 Markdown 样式，接近 SAP Fiori 的浅色风格。
- **找文件**：在原右侧文件筛选框输入 `report md`，查找名称或路径含 `report` 的 `.md` 文件；再加 `docs` 缩小路径范围。
- **定位**：启用 UX 后，打开文件会展开父目录、选中并定位文件树节点。搜索和文件树跟随一起用，需要同时启用 Navigation 和 UX。
- **阅读**：原“切换审查”按钮或 **Ctrl+Shift+R** 在右侧隐藏和全宽之间切换，替代普通分栏切换。全宽时暂时隐藏对话，不是 Windows 全屏。
- **打开文件**：回复或末尾文件清单中的路径有下划线时，可以点击或按 Enter 在右侧打开。文件必须存在，插件不自动生成清单。
- **编辑**：先用不重要的本地文本副本试。点 **编辑**，改完点 **保存**或按 **Ctrl+S**。**放弃修改**会丢弃草稿，关闭窗口前先保存。
- **执行过程**：工具组运行时自动展开，显示命令和操作摘要；完成后在后续回答或执行结束时收拢，仍可展开查看原始细节。
- **文件操作**：工具栏提供复制、下载、资源管理器和编辑器选择。

## 更新或移除

先保存编辑内容，再关闭对应插件。更新时把旧文件夹移到 **plugins 之外**作为备份，然后复制新文件夹到原位置，不混合新旧文件。

移除时把对应文件夹移出 `C:\Users\<your user>\.config\opencode\plugins`，不要放进它的其他子目录。Fiori 用户先切回原主题。

## 有问题时

先检查文件夹层级、插件开关和 OpenCode 版本。保存被拒绝可能是大小、编码、权限或外部修改导致，关闭窗口前先把草稿复制到安全位置。
